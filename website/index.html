Téléchargez Buchat

Disponible sur toutes vos plateformes. Aucun compte App Store ou Play Store requis.

iPhone & iPad

Version Web Progressive — fonctionne dans Safari.

  1. Ouvrez buchat.bujaonline.com/app dans Safari
  2. Appuyez sur Partager ⬆️
  3. Choisissez « Ajouter à l'écran d'accueil »
Installer sur iPhone
🤖

Android

Fichier APK — installation directe.

  1. Téléchargez le fichier APK ci-dessous
  2. Ouvrez-le (autorisez "sources inconnues" si demandé)
  3. L'appli apparaît sur votre écran d'accueil
Télécharger l'APK v1.0.0 · ~30 Mo
🖥️

Windows 10/11

Installateur .exe — double-clic pour installer.

  1. Téléchargez Buchat-Setup.exe
  2. Double-cliquez et suivez l'assistant
  3. Lancez Buchat depuis le menu Démarrer
Télécharger pour Windows v1.0.0 · ~85 Mo
🍎

macOS

Image disque .dmg — glissez dans Applications.

  1. Téléchargez Buchat.dmg
  2. Ouvrez et glissez dans Applications
  3. Lancez depuis le Launchpad
Télécharger pour macOS v1.0.0 · ~90 Mo
🐧

Linux

AppImage portable — aucune installation.

  1. Téléchargez Buchat.AppImage
  2. Rendez-le exécutable : chmod +x
  3. Double-cliquez pour lancer
